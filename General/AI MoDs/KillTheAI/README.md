This is a bundle of 3 maps by Mortal Combatant designed for 3* human players to fight against AI. Additionally it delivers a special gamemode "KillTheAI" which may (you are able to turn it off) disable some researches for the players (3 first lobby slots), and adds some free technologies to the AI. Maps contain prebuilt bases with extensive fortifications. 

The game shouldn't be able to be won as a single participant.
